GOOGLE SEARCH GUIDANCE APPLIED
1. Each indexable page has one absolute, self-referential canonical URL in the HTML source.
2. Canonical URLs and sitemap <loc> URLs match exactly.
3. Internal navigation uses the preferred directory URLs with trailing slashes.
4. Legacy and duplicate paths are permanently redirected where the static host supports the included _redirects rules.
5. robots.txt does not block the site's HTML, CSS, JavaScript or local images.
6. Page titles and descriptions are unique and relevant to each page.
7. Open Graph metadata, structured data and image previews use absolute URLs on the primary domain.

HOST CONFIGURATION STILL REQUIRED
The code package cannot configure DNS, TLS certificates, web-server virtual hosts or Google Search Console on your behalf.
- Set kairosecocleaning.com as the primary hostname.
- Enable HTTPS.
- Permanently redirect http://kairosecocleaning.com/ and https://www.kairosecocleaning.com/ to https://kairosecocleaning.com/.
- For Apache hosting, .htaccess is included. For Cloudflare Pages/static hosting, configure the equivalent www-to-root and HTTP-to-HTTPS redirect rules in the hosting dashboard.
- Once live, open /robots.txt and /sitemap.xml in a browser, then verify the domain property and submit the sitemap in Google Search Console.
